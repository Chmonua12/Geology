# Монолит Адыгеи

«Монолит Адыгеи» — интерактивное мини-обучение по геологической безопасности. Пользователь проходит четыре учебных этапа, учится распознавать признаки карста, оползней и обвалов, знакомится с инженерной защитой и получает сертификат.

## Что сделано для UX-практикума

- добавлен вводный экран с целью, длительностью и ожидаемым результатом;
- сохранение и продолжение маршрута;
- повторное прохождение без ручной очистки браузера;
- сбор учебных метрик: ошибки, подсказки, этапы и время;
- оценка понятности маршрута и текстовый комментарий;
- видимые состояния фокуса, управление клавиатурой и поддержка уменьшенной анимации;
- подготовлен комплект артефактов по шаблонам 1–21.

Основной отчёт: [docs/UX_PRACTICUM.md](docs/UX_PRACTICUM.md).

Чек-лист защиты: [docs/RUBRIC_CHECKLIST.md](docs/RUBRIC_CHECKLIST.md).

Протокол учебного тестирования: [docs/TEST_PROTOCOL.md](docs/TEST_PROTOCOL.md).

## Запуск основного сайта

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

После запуска открыть `http://127.0.0.1:8000/`.

GeoChat использует только ответы Polza AI. Ключ задаётся переменной `POLZA_API_KEY` в файле `.env` (старое имя `POLZA_AI_API_KEY` тоже поддерживается), пример находится в `.env.example`. Если ключ отсутствует или Polza API временно недоступен, интерфейс показывает ошибку и не подставляет заготовленный ответ.

## Персональная экспедиция и MCP

Во время прохождения сайт отправляет в локальный API обезличенные учебные метрики: время, количество ошибок, подсказок, пройденных этапов и ошибки по темам. После четырёх этапов MCP передаёт эти данные Polza AI и заполняет итоговую форму рядом с сертификатом. Точные числа берутся из игры, нейросеть формулирует только вывод, сильную тему, тему для повторения и итоговый уровень.

Технологии дополнительного модуля:

- Vite + React — форма и готовый персональный маршрут;
- Bun — API, WebSocket и SQLite;
- MCP — получение прогресса и заполнение открытых форм через WebSocket;
- Playwright не используется.

После установки Python-зависимостей и [Bun](https://bun.sh/) выполнить в корне проекта одну команду:

```powershell
bun install
bun run dev
```

Команда одновременно запускает весь проект:

- `http://127.0.0.1:8000/` — основной Django-сайт;
- `http://127.0.0.1:5173/` — конструктор экспедиции;
- `http://127.0.0.1:3001/api/health` — Bun API;
- `http://127.0.0.1:3001/mcp` — встроенный HTTP MCP-сервер.

На итоговом экране есть кнопка «Настроить персональную экспедицию», которая передаёт тот же ID ученика в Vite-приложение.

### Подключение MCP

1. Запустить весь проект командой `bun run dev`.
2. Для локальной разработки подключить MCP-клиент к `http://127.0.0.1:3001/mcp`. Для Render использовать защищённую настройку из `mcp.json.example`.
3. Перезапустить MCP-клиент.

Для клиента, который поддерживает только stdio, сохранена совместимая команда `bun run mcp`.

Сервер предоставляет три инструмента:

- `get_learning_progress` — получает результаты ученика;
- `fill_expedition_form` — заполняет открытую форму через WebSocket;
- `fill_final_results` — получает разбор от Polza AI и заполняет итоговую форму на экране сертификата.

Пример запроса ассистенту: «Подведи итоги прохождения ученика `student-...` и заполни итоговую форму на открытом сайте».

Подробная схема и сценарий демонстрации: [docs/MCP_PERSONAL_EXPEDITION.md](docs/MCP_PERSONAL_EXPEDITION.md).

### Render

Основная игра работает на `https://geology-0en5.onrender.com/`. Файл `render.yaml` создаёт второй сервис `geology-mcp`, который одним процессом обслуживает Vite-форму, API, WebSocket и MCP endpoint. Пошаговая настройка и список секретов: [docs/RENDER_MCP.md](docs/RENDER_MCP.md).

Для полной проверки проекта:

```powershell
bun run check
python manage.py test
```

## Структура проекта

- `expedition/templates/expedition/index.html` — пять экранов маршрута, вводный экран и форма оценки;
- `expedition/static/expedition/app.js` — задания, навигация, сохранение прогресса и метрики;
- `expedition/static/expedition/styles.css` — визуальная система и адаптивные состояния;
- `expedition/views.py` — главная страница и API GeoChat;
- `frontend/` — Vite-форма персональной экспедиции;
- `mcp-server/` — Bun API, SQLite, WebSocket и MCP-сервер;
- `docs/` — материалы практикума и проверки.

## Важное замечание о данных

Числа в отчёте помечены как учебный ролевой прогон. Они нужны для демонстрации заполнения шаблонов и логики «до/после», но не заменяют исследование с реальными школьниками. Перед публичной защитой достаточно провести 3–5 коротких тестов по готовому протоколу и заменить демонстрационные строки фактическими результатами.
