# ГеоДрон — адаптивные мини-миссии

Первая реализация для «Монолита Адыгеи» без замены исходных игровых экранов.

## Как это работает

- Две ошибочные попытки в одной геологической теме включают обучающую мини-миссию («разведку»).
- Три правильных действия подряд в одной теме включают экспертную миссию.
- В обучающей миссии нужно найти 2 объекта, в экспертной — 3; экспертная карта содержит дополнительные опасные клетки.
- Управление: стрелки клавиатуры или экранные кнопки. Дрон не пересекает опасные клетки; пояснения помогают понять каждый найденный признак.
- Миссия не блокирует основную игру: её можно закрыть в любой момент.
- Результаты хранятся в localStorage. Если локальный Bun API запущен, они дополнительно записываются в SQLite.
- Автоматический запуск по количеству ошибок/успехов выполняется JavaScript, **без необходимости вызывать MCP на каждый клик**.

## Проверка

1. Запустить Django: `python manage.py runserver`.
2. Открыть основную экспедицию и дважды выбрать неверный объект в Лаго-Наки или Каменномостском.
3. Появится окно «ГеоДрон». Использовать стрелки, найти два объекта и закрыть миссию.
4. Перезапустить экспедицию, выполнить три правильных действия подряд — откроется экспертная миссия.
5. При запущенном `bun run dev` результаты доступны в `GET http://127.0.0.1:3001/api/trials/<learnerId>`.

## MCP

Два новых инструмента:
- `get_geodrone_results`: возвращает историю мини-миссий, по которой ИИ-клиент может анализировать сложности ученика.
- `launch_geodrone_trial`: после подтверждения пользователя просит локальный Bun API отправить WebSocket-событие `trial:launch` на открытую страницу основного сайта.

Для MCP-запуска браузер должен находиться на `localhost` или `127.0.0.1`, а Bun API — на `127.0.0.1:3001`. MCP-клиент должен быть запущен отдельно (команда `bun run mcp`).

## Границы версии

- Это локальный прототип: на Render WebSocket и URL `127.0.0.1:3001` автоматически не заработают. Для публикации понадобятся настраиваемый адрес API, CORS, защищённая аутентификация пользователя и HTTPS/WSS.
- В существующем Bun API внутренние маршруты не защищены полноценной аутентификацией. Не публикуйте эти управляющие эндпоинты в интернете без защиты.
- В текущем коде нет автономного ИИ-агента, постоянно вызывающего MCP. MCP-инструменты доступны подключённому клиенту и могут быть вызваны им по запросу.
- Результаты новых мини-миссий не входят в оценку основного сертификата.
