# ГеоРадар — иллюстрированное окно с вопросами

Дополнительные вопросы появляются после неправильного ответа на первых трёх этапах «Монолита Адыгеи». В этапе с Flappy Bird окно отключено. Дизайн использует зелёную рамку с биноклем, горами и растениями из файла `expedition/static/expedition/georadar-window.png`. Внутри рамки размещены настоящие HTML-элементы: вопрос, четыре варианта ответа, обратная связь и кнопка перехода.

## Проверка

1. Запустите Django: `python manage.py runserver`, затем откройте сайт и начните экспедицию.
2. Допустите ошибку на одном из первых трёх этапов: корректирующее окно откроется автоматически.
3. При выборе ответа карточка анимируется: верный — плавное зелёное увеличение, неверный — мягкое покачивание и подсказка.
4. В каждом вопросе отображаются четыре варианта без буквенных маркеров.

## Структура

- `expedition/static/expedition/georadar-window.png` — иллюстрированная рамка дополнительного задания.
- `expedition/static/expedition/georadar.css` — позиционирование живого HTML поверх светлой области и мобильный вариант.
- `expedition/static/expedition/georadar.js` — вопросы и варианты, проверка, анимационные состояния, сохранение результатов.
- `expedition/templates/expedition/index.html` — подключение ресурсов с обновлёнными версиями для обхода кеша.

Задания продолжают учитывать ошибки `app.js`. Данные сохраняются локально. MCP через Bun доступен только в локальной конфигурации, как и раньше.

## Render

При деплое Django требуется `python manage.py collectstatic --noinput`. В браузере откройте страницу с полной перезагрузкой, проверьте, что `/static/expedition/georadar-window.png` и `/static/expedition/georadar.css` возвращают HTTP 200.
