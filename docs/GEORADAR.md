# ГеоРадар — адаптивная мини-игра

Новая дополнительная мини-игра «ГеоРадар» не заменяет существующие экраны «Монолита Адыгеи». Она открывается отдельным окном (HTML `<dialog>`) поверх панорамы или Flappy-игры.

## Как увидеть

1. Запустите Django: `python manage.py runserver`.
2. На любом игровом экране нажмите видимую кнопку **«✺ ГеоРадар»** в левом нижнем углу — запустится тренировочная версия без необходимости ошибаться.
3. В основной игре допустите **две ошибки в одной теме**: GeoRadar автоматически откроет тренировочную миссию из двух ситуаций.
4. Три правильных действия подряд в одной теме запускают экспертную миссию из трёх ситуаций с тремя вариантами ответа.

В каждом раунде игрок выбирает геологически правильный ответ из карточек. При неверном выборе получает подсказку и может попробовать снова; правильное решение сопровождается кратким объяснением.

Варианты автоматически перемешиваются. Четыре набора заданий: карст, оползни, обвалы/осыпи и инженерная защита. Результаты хранятся в `localStorage` под ключом `geoshield-georadar-results-v1`.

## Интеграция MCP

При локальном запуске основного Django-сайта и Bun API результаты также отправляются в SQLite (`POST /api/radar`), доступны в `GET /api/radar/:learnerId`. Добавлены MCP-инструменты:
- `get_georadar_results` — получить результаты для анализа.
- `launch_georadar_mission` — отправить на открытый сайт выбранную миссию после явного подтверждения пользователя.

Команды MCP отправляются Bun через WebSocket только для сайта на localhost / 127.0.0.1. Для проверки запустите `bun run dev` и подключите MCP-клиент через `bun run mcp`.

На Render Django показывает мини-игру и адаптирует её локально без Bun. Для удалённого MCP-подключения требуется отдельно развернуть Bun API, указать HTTPS/WSS-адрес, защитить API и настроить проверку пользователя. Нынешние управляющие маршруты Bun рассчитаны **только на локальную разработку**, публиковать их без авторизации нельзя.

## Изменения

- `expedition/static/expedition/georadar.js`: игровая механика, сценарии, адаптивные триггеры.
- `expedition/static/expedition/georadar.css`: адаптивное всплывающее окно.
- `expedition/templates/expedition/index.html`: подключение ресурсов.
- `expedition/static/expedition/app.js`: интеграция с уже существующими счётчиками ошибок и правильных действий.
- `mcp-server/src/api.ts`, `database.ts`, `mcp.ts`: сохранение истории и MCP-инструменты.

## Проверка

- Проверить, что CSS и JS загрузились с ответом 200 (в Render используется `collectstatic`).
- На сайте нажать «✺ ГеоРадар», выбрать ответы, убедиться, что появляется объяснение и переход к следующей ситуации.
- Повторить на мобильном экране.
- После двух ошибок на одном экране дождаться автоматически открывшегося окна.
- При необходимости проверить локальные Bun тесты: `bun run check` и Django: `python manage.py test`.
