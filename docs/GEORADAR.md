# ГеоРадар — иллюстрированное окно с вопросами

Дополнительные вопросы появляются поверх прежних игровых экранов «Монолита Адыгеи». Дизайн использует зелёную рамку с биноклем, горами и растениями (отдельный прозрачный файл `expedition/static/expedition/georadar-frame.avif`). Текст вопроса, варианты ответа, кнопка закрытия и следующий вопрос остаются настоящими HTML-элементами. Надписи «Миссия» и «Георадар» удалены **из всплывающего окна**.

## Проверка

1. Запустите Django: `python manage.py runserver`, затем откройте сайт и начните экспедицию.
2. Нажмите «✺ Доп. задание» слева внизу, чтобы увидеть новое окно сразу.
3. Или допустите **две ошибки в одной теме**: автоматически откроется тренировочный вариант из двух ситуаций.
4. Три верных действия подряд в одной теме открывают более сложный вариант из трёх вопросов.
5. При выборе ответа карточка анимируется: верный — плавное зелёное увеличение, неверный — мягкое покачивание и подсказка.
6. Работают четыре темы: карст, оползни, обвалы и инженерная защита.

## Структура

- `expedition/static/expedition/georadar-frame.avif` — иллюстрация с прозрачностью. Сжатая версия исходного изображения, оптимизированная для загрузки.
- `expedition/static/expedition/georadar.css` — позиционирование живого HTML поверх светлой области и мобильный вариант.
- `expedition/static/expedition/georadar.js` — вопросы и варианты, проверка, анимационные состояния, сохранение результатов.
- `expedition/templates/expedition/index.html` — подключение ресурсов с обновлёнными версиями для обхода кеша.

Задания продолжают учитывать ошибки `app.js`. Данные сохраняются локально. MCP через Bun доступен только в локальной конфигурации, как и раньше.

## Render

При деплое Django требуется `python manage.py collectstatic --noinput`. В браузере откройте страницу с полной перезагрузкой, проверьте, что `/static/expedition/georadar-frame.avif` и `/static/expedition/georadar.css` возвращают HTTP 200.
