# MCP-механика «Итоговый разбор экспедиции»

## Зачем она нужна

После четырёх учебных этапов у ученика есть измеримые результаты: время, ошибки, подсказки и ошибки по четырём темам. MCP получает эти данные, просит Polza AI сформулировать краткий педагогический вывод и заполняет итоговую форму рядом с сертификатом.

## Как устроен сценарий

1. Django-сайт сохраняет прогресс в браузере и отправляет его в Bun API.
2. Bun API одновременно предоставляет встроенный MCP endpoint `/mcp`; отдельный MCP-процесс не требуется.
3. На экране сертификата сайт поддерживает WebSocket-соединение с тем же ID ученика.
4. MCP-инструмент `get_learning_progress` получает точные результаты.
5. MCP-инструмент `fill_final_results` передаёт обезличенные числа Polza AI.
6. Bun API объединяет исходные метрики и текстовый анализ нейросети.
7. Заполненная форма появляется на открытом сайте без перезагрузки.
8. Ученик проверяет данные и нажимает «Сохранить разбор».

## Почему числа нельзя изменять нейросети

Время, этапы, ошибки и подсказки копируются из SQLite без изменения. Polza AI получает только обезличенную статистику и возвращает четыре текстовых поля: сильную тему, тему для повторения, уровень и краткий комментарий. Если API недоступен, форма не подставляет заготовленный анализ.

## Данные

Локальная SQLite-база находится в `mcp-server/data/geology.sqlite` и не попадает в Git. В ней четыре таблицы:

- `progress` — последний прогресс ученика;
- `drafts` — последний черновик формы;
- `radar_results` — результаты дополнительных заданий;
- `routes` — созданные маршруты.

Персональные данные не запрашиваются. ID создаётся случайно и хранится в `localStorage` браузера.

## Демонстрация на защите

1. Запустить Django, Bun API, встроенный MCP и Vite одной командой: `bun run dev`.
2. Пройти часть основной экспедиции и специально допустить ошибку.
3. На итоговом экране скопировать ID ученика из формы.
4. Попросить MCP подвести итоги и заполнить итоговую форму.
5. Показать, что поля меняются без перезагрузки страницы.
6. Проверить значения и сохранить разбор.

HTTP MCP endpoint: `http://127.0.0.1:3001/mcp`. Пример конфигурации находится в `mcp.json.example`.

## Проверка без MCP-клиента

Работу инструмента проверяют при открытом итоговом экране и сохранённом прогрессе четырёх этапов:

```powershell
$body = @{ learnerId = "student-demo" } | ConvertTo-Json

Invoke-RestMethod -Method Post -Uri http://127.0.0.1:3001/api/internal/final-results -ContentType application/json -Body $body
```
